# True Rides Japan — сайт

Клиентский сайт trueridesjapan.com: японские авто с аукционов (Alphard/Vellfire, Nissan Note e-Power), путь Япония → Поти → переделка руля в Грузии → выдача в Одессе/Киеве.
Владелец: Виталий. Общается по-русски, вопросы задавать по одному.

## Структура
- Сайт статический, генерируется скриптом: **`python3 _src/build.py`**. HTML-файлы в корне, `ua/`, `en/`, `cars/`, `toyota-alphard-vellfire/`, `nissan-note-e-power/`, а также `sitemap.xml` и `robots.txt` — результат генерации, руками их не править.
- Данные: `data/cars.json` (машины, публичные поля), `data/images.json` (фото — только локальные `assets/cars/TR-XX-N.jpg`; с 13 ноября ссылок на BeForward нет: в их адресах номер машины CF…/CE…, а на фото подпись «BE FORWARD Ref #» — её срезаем, нижние ~7% кадра 640×480).
- Шаблоны и тексты: `_src/build.py`, `_src/i18n.json` (интерфейс), `_src/texts.json` (SEO-тексты главной и страниц моделей), `_src/articles.json` (статьи `/blog/<slug>/` на трёх языках, список статей — `/blog/`), `_src/dicts.json` (цвета, опции, порты), `_src/page.css` + `_src/extra.css`, `_src/main_sections.html` (разделы главной).
- Язык главной (решение 10 ноября): `functions/_middleware.js` (Cloudflare Pages Function) — новый посетитель главной `/`: из Украины или телефон на украинском → `/ua/`; телефон на английском → `/en/`; остальные — русская главная. Ручной выбор языка запоминается cookie `tr_lang` и отменяет переадресацию. Поисковые роботы не перекидываются (индекс не трогаем). Проверка: `/?geo=UA`, `/?al=en`.
- Языки: русский — корень `/`, украинский — `/ua/`, английский — `/en/`. Страница машины: `/cars/tr-05/`, `/ua/cars/tr-05/`…
- Статьи со свободным текстом: в `_src/articles.json` поле `"free": true`, тело — `_src/articles/<slug>.<lang>.html`. Поле `"langs"` — на каких языках есть статья (если не все). Армянский `/hy/` есть только у статьи для Армении; интерфейс на армянской странице — русский. Поле `faq` → разметка FAQPage.
- Счётчик нажатий (11 ноября): в `_src/seo.json` поля `ga4` (G-…), `ads` (AW-…), `ads_label` — если заданы, на все страницы ставится Google tag; нажатия на Telegram/Viber/WhatsApp/«Позвонить» шлют событие `contact_click` (method, car) и конверсию Google Ads. Пусто — ничего не подключается.
- SEO: `_src/seo.json` — коды подтверждения Google Search Console / Яндекс Вебмастер / Bing (вставляются мета-тегом во все страницы) и ключ IndexNow (файл `<ключ>.txt` в корне). Сборка также пишет `llms.txt` (описание сайта для ИИ-ассистентов).
- Хостинг: Cloudflare Pages, автодеплой из ветки `main` (без команды сборки — HTML коммитится готовым).
- Порядок правки: изменить данные/шаблоны → `python3 _src/build.py` → проверить → commit → push в `main`.

## Правила
- На сайте НИКОГДА не публиковать: себестоимость, номера лотов, номера кузовов (шасси), грузополучателя, email, данные CAP/коносамента (кроме номера контейнера — его показываем). Это только для будущей админки.
- Номера машин для клиентов: TR-01, TR-02… (не номера аукциона).
- Статусы машин считаются по датам `etd`/`eta` из `data/cars.json` (ждёт отправки → в пути → прибыл в Поти) при сборке и ещё раз в браузере посетителя. Руль: «правый — переставляется на левый в Грузии перед отправкой в Украину».
- Цены: «Украина» — цена с растаможкой в Украине (сертификацию и постановку на учёт на сайте не расписываем, это обсуждается с клиентом лично); «Грузия» — подпись «Грузия, в Поти»; это цена из объявлений на MyAuto.ge, в Поти; портовые 470 лари (с реэкспортом) мы платим всегда и они уже сидят в этой цене — перекуп сверху не доплачивает, зато ему не нужен реэкспорт (уточнено 12 ноября; без доставки до Рустави; про переделку руля не пишем). Цена «Украина» = Грузия + портовые $200 + Поти→Рустави $150 + переделка (Note HE12 $500, Note E13 $1 700, Alphard/Vellfire 20 $1 600, 30-й $2 900) + автовоз $950 + растаможка (HE12 $2 500, E13 $2 580 (117 300 грн, Кар-Юнион, 9 ноября), A/V 20 $3 500, 30-й $3 530) + $400, округление вверх до сотни (решение 8 ноября). Цены «Украина» на сайте НЕ пересчитывали после уточнения расходов 12 ноября (порт 470 лари ≈ $181 + Поти→Рустави 450 лари ≈ $173 вместо $200 + $150 — разница $4, решено оставить). Себестоимость (для маржи) = инвойс + фрахт (Note $1 140, Alphard/Vellfire $1 900) + 470 лари + $100 украинской фирме, пока получатель не сменён; лари по 2,6. Принцип Виталия: расходы закладывать по верхней границе — лучше видеть меньше маржи, чем больше. Себестоимость и маржу в репозиторий не класть — они в закрытой странице Claude «True Rides — маржа» (artifact a274d8dc-647c-4b6c-b751-8d25eadab149; при смене цен/инвойсов — обновлять её).
- Растаможка для клиента: на странице машины под ценой «Украина» строка «В т. ч. растаможка ≈ $X» (`CUSTOMS`/`customs()` в build.py, округление до сотни; решение 10 ноября). В «Как забронировать»: остаток для Украины = цена «Украина» − бронь − растаможка.
- Примечание к машине: поле `note` в cars.json `{"ru","uk","en"}` — показывается на странице машины (например, TR-10: бампер под покраску).
- Контакты: +380663666886 — Telegram, Viber, WhatsApp (везде на виду); грузинский +995511184186 — только кнопка «Позвонить» и строка «Звонки» в разделе «Контакты» на главной; t.me/truerides_chat, instagram.com/true_rides.

## Решения (8 ноября 2026)
- Бронь — 50% от цены «Грузия», одинаково для всех направлений (`deposit()` в build.py; решение 9 ноября, раньше были фиксированные суммы по кузовам). Цена фиксируется в момент брони. Остаток — за 10–15 дней до прибытия в Поти: Грузия — остаток по цене «Грузия», машина с правым рулём; Украина — остаток без растаможки, растаможка оплачивается по прибытии машины в Украину. Отказ — бронь возвращается с удержанием $500. Раздел «Как забронировать» на главной (`#booking`).
- Выдача: Поти, Рустави, Одесса, Киев.
- Не публиковать: имена/адреса мастеров переделки руля (отдельной страницы переделки НЕ делаем — переделкой не занимаемся); описание ремонтов машин (аукционный лист — только по запросу); Осетию и Россию как направления.
- Расписание: названия судов (`vessel`, `vessel2` в cars.json) на сайте НЕ показываются, только маршрут «порт → Поти» и даты. Номер контейнера — поле `container` в cars.json, на странице машины строка «Контейнер» со ссылкой на отслеживание MSC (решение 8 ноября); `data/meta.json` — дата последней сверки с BeForward (менять при каждом обновлении дат). TR-02: рабочая ETA 08.12.2026 по трекингу MSC, CAP показывает 25.11.2026 — расхождение, перепроверять.
- 404.html сразу уводит посетителя в каталог (для поисковиков код 404).
- Порядок дальше: Виталий проходит курс и смотрит сайт → цены и его правки → счётчик нажатий на мессенджеры → Google Ads → админка (своя; идеи из панели ChatGPT: калькулятор маржи, статусы кнопкой, история, CAP/аукционный лист). Анимация прокрутки на главной — когда скажет.
- Страница /toyota-alphard-vellfire/ (сделано 11 ноября): подробный рассказ — `_src/models/minivan.<lang>.html` (ru/uk/en), картинки в `assets/models/alphard/`; `{min30}` = мин. цена 30-го кузова, `{conv_url}` = статья про переделку. Смысл: «премиальный минивэн для семьи или для работы, по доступной цене»; Alphard бывает 7–8 мест, возим в основном 7-местные. В «Статьях» — карточка со ссылкой на эту страницу. Note — пока без такого рассказа.
